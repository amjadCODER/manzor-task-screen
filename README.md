# Manzor Task Screen

نظام الخطط والمهام وشاشة المتابعة العامة.

## المسارات

- `/` تسجيل الدخول برقم الايدي نفسه المستخدم في منظور Vault.
- `/employee/1` مثال شاشة الموظف الخاصة.
- `/monitor` شاشة متابعة جميع الموظفين.

## المستخدمون الحاليون

- 1 — امجاد البشير
- 5 — منير عبدالله
- 3 — امين حسن
- 6 — عبدالوهاب عبدالله
- 4 — البشير حسن
- 8 — مشاري
- 7 — فايز

تم حذف بيانات الموظفين التجريبية السابقة. المهام والخطط تضاف من شاشة الموظف، والحفظ الحالي محلي الى حين ربط Supabase.
